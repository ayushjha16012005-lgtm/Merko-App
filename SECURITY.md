# Security Policy

## Supported Versions

We actively support and patch security issues in the following versions of the MERKO platform:

| Version | Supported |
| ------- | --------- |
| v1.0.x  | Yes       |
| < v1.0  | No        |

## Reporting a Vulnerability

We take the security of the MERKO platform seriously. If you find a security vulnerability, please do **NOT** open a public issue. Instead, report it privately to our security team.

Please report vulnerabilities by emailing **security@merko.com** with the following information:

* A detailed description of the vulnerability and its potential impact.
* Step-by-step instructions (or a proof-of-concept script/exploit) to reproduce the issue.
* Any details about the environment or configurations in which the issue was discovered.

Once we receive your report:

1. We will acknowledge receipt of your vulnerability report within 48 hours.
2. We will investigate the issue and coordinate a fix.
3. We will keep you updated on our progress toward resolving the issue.
4. We will issue a patched release and publish a security advisory once the fix is deployed.
